# Contributing to entsoe-py

Contributions, either in issues or pullrequests, are always welcomed! ```entsoe-py``` is a community project and everyone is invited to help to improve the package.  
You are kindly requestd to follow below guidelines to smooth the process for everyone involved, thanks in advance!

## Issues
When reporting issues/bugs or doing feature requests, please write a clear and concise description. Please search existing issues first. For a bug report, include steps to reproduce, as well as the expected and actual behavior you are experiencing.  
 Please provide a minimum reproducible example for any reporting you do. This should be a python code snippit, be careful to not accidentally copy your API key into it!  
If reporting a bug your snippit should showcase the bug, when requesting a feature the snippit should show how you envision to use the feature.  
At all times please follow the AI usage guidelines below.

## Older Version Support
In principle there is no support for older versions, always update the package before reporting an issue!  
To keep maintenance manageable, requests to lower python or dependencies version requirements are in principle never accepted unless proven to be fully compatible with the latest version of the package.

## Pull Request
When creating a pull request please follow below guidelines:
* Always run the live tests and make sure they succeed, api keys are free.
* Never create offline tests, always integrate into the live ones. The reason for this is that the entsoe API has a habit of changing their API with little notice.
* Always include a proper minimum reproducible example. This should be a python code snippit.
* If you believe a test should be changed, clearly indicate this and give a clear and concise explanation of why
* AI assistance is fine, make sure you understand the code however and follow the AI guidelines below

## AI Assistance Policy
On AI usage: If you want to use AI that is fine, but be mindful how you use it. If you find an issue with AI, please use AI assistance to create a fix and open a pull request.  
Make sure you have verified any code you want to contribute yourself!  
**Do NOT copy and paste AI text directly.** Pure AI vomit with walls of text **will** be closed and not read. Repeat offenders **will** be banned from contributing.  

An agent can never be responsible as it is a machine, **you the human are responsible** for what you are contributing.
